# 大乱斗游戏厅

纯 HTML5 Canvas 制作，无任何依赖，双击 `index.html` 即可游玩（也可用任意静态服务器打开）。

```bash
python -m http.server 8383
```

## 🐍 贪吃蛇大乱斗（snake.html）
- 鼠标控制方向，左键 / 空格加速（加速会消耗长度并掉落能量）
- 头撞到别的蛇身体就会死，用身体拦截对手、吞掉它爆出的能量
- 道具：🧲 磁铁（远距离吸食）、⚡ 疾风（免费加速）、🛡️ 护盾（穿越身体）、✨ 双倍成长
- 🌠 流星雨事件：定期在地图某处降下大量能量，小地图会闪烁提示
- 28 条性格各异的 AI 蛇（会围剿、抢道具、追流星雨）

## 🫧 球球大乱斗（ball.html）
- 鼠标控制移动，空格分裂，W 吐球，滚轮缩放
- 比对方大 25% 才能吃掉它；分裂可以突袭，但分身要过一会儿才能合体
- 🦠 大球碰到病毒会被炸成碎片；往病毒里吐 7 个球会把病毒射出去
- 道具：🧲 磁铁、⚡ 疾速、🛡️ 护盾；🍬 糖果雨事件
- 果冻形变的小球，会眨眼、会害怕、会坏笑的 AI

手机 / 平板支持触屏摇杆和按钮。最佳成绩保存在浏览器本地。

## 文件结构
```
index.html      游戏大厅
snake.html      贪吃蛇大乱斗
ball.html       球球大乱斗
css/style.css   公共样式（HUD、弹窗、触屏控件）
js/common.js    公共库：输入、空间网格、合成音效、粒子、排行榜等
js/snake.js     贪吃蛇逻辑与渲染
js/ball.js      球球逻辑与渲染
```
